2026-11-21 · 第 3 课串路线
先看全局

一共三条路线，每条给一个字母

路线字母用大白话说：干什么分值难度练的顺序
② 送珍宝B四个角各拿一件珍宝，开进中间博物馆，四个人一共 40 分40＋10（全到）容易第 1 个练
③ 放石柱C从万神殿出发，把旁边的石柱勾回来、立直10中等第 2 个练
① 打两球A从奇琴伊察开进球门中间，把两个球打出去；球落地后把奖杯推进安全区30（两球）＋10（奖杯）最难最后练
字母怎么念：字母＝第几条路线，后面的数字＝第几步。A1 念「A-1」，就是路线 A 的第 1 步；B3 就是路线 B 的第 3 步。图上写什么字母，程序就叫什么名字，找起来不费劲。
顺序不是随便定的：先拿不用机械臂、路线最稳的分，再练手臂，最后攻最难的两球。同一节课只跑一条线，别三条一起上。
完整地图

三条线画在一张图上

A 打两球 B 送珍宝 C 放石柱
三种颜色 = 三条不同的活，不是一辆车同时跑。
一轮 2 分钟只能选一条线跑。换线之前，先把车摆回安全区、对准方向，再跑。
  • 实线 = 开过去的路线；虚线 = 倒回来
  • 一条线 = 一段程序，从安全区出发，到另一个安全区或博物馆停下
  • 每条线旁边的字母，就是这段程序的文件名
  • 线画在图上，程序照线上写，跑通就把线描成实线
后三页每条线单独放大：左边是图，右边是「第几步干什么」和「程序怎么写」。
A路线 ①·打两球 · 最难

奇琴伊察 → 两球门中间 → 回安全区

步从 → 到做什么程序块
A1奇琴伊察 →两球门中间车头对准两个球门的中间，直直开过去马达A 顺时针 功率8 → 等 2.4 秒 → 停
A2站在中间推板伸出去，把两个球一起扫出球门、落地马达B 顺时针 功率7 → 等 1.2 秒 → 反转 0.8 秒收回
A3球门 → 奇琴伊察原路倒车回安全区停住马达A 逆时针 功率8 → 等 2.4 秒 → 停
A4奇琴伊察 → 奖杯两球都落地后，把奖杯推进安全区（可选，+10）马达A 正转 0.8 秒 → 推板推一下
坑：球门是两个小洞，球要「推离球门、掉到地上」才算；车别压到球门圈，压了也算碰任务品。A4 一定要等两个球都落地再做，否则奖杯不算分。
B路线 ②·送珍宝 · 最容易

四个角各拿一件，开进博物馆

步从 → 到做什么程序块
B1万神殿 → 博物馆带上红色珍宝，直行进中央圈停住马达A 顺时针 功率6 → 等 3.4 秒 → 停
B2舒什塔尔 → 博物馆带上蓝色珍宝，直行进中央圈停住同上，等 4.1 秒
B3奇琴伊察 → 博物馆带上黄色珍宝，直行进中央圈停住同上，等 3.6 秒
B4吴哥窟 → 博物馆带上绿色珍宝，直行进中央圈停住同上，等 4.4 秒
四条线其实是同一套程序，只是起点不同、秒数不同。2 分钟一般只跑 2 趟：先跑最近、最直的那一趟，别贪四趟全跑，跑不完还压线。
C路线 ③·放石柱 · 中等

万神殿 → 石柱 → 带回来立直

步从 → 到做什么程序块
C1万神殿 → 石柱旁车头对准石柱，开过去停在它前面马达A 顺时针 功率6 → 等 1.8 秒 → 停
C2石柱旁手臂放下去，勾住石柱马达B 顺时针 功率5 → 等 1.5 秒 → 反转 0.6 秒夹紧
C3石柱 → 万神殿倒车把柱带回安全区，到位置把手臂抬起，让柱立直马达A 逆时针 功率6 → 等 1.8 秒 → 停；马达B 抬起
坑：石柱分三步拿：勾住、带走、立直。少了「立直」这一步，柱子躺在地上不算分；进安全区以后手臂要松开、抬起来，别一直夹着。
程序清单

按步骤号排，一个程序干一件事

程序名积木怎么排参考秒数
A1马达A 顺时针 功率8 → 等待 2.4 秒 → 马达A 停止2.4
A2马达B 顺时针 功率7 → 等待 1.2 秒 → 马达B 逆时针 功率7 → 等待 0.8 秒 → 停止2.0
A3马达A 逆时针 功率8 → 等待 2.4 秒 → 马达A 停止2.4
A4马达A 顺时针 功率5 → 等待 0.8 秒 → 停止 → 马达B 推 0.6 秒约 1.4
B1～B4马达A 顺时针 功率6 → 等待（各自秒数，见下）→ 马达A 停止3.4 / 4.1 / 3.6 / 4.4
C1马达A 顺时针 功率6 → 等待 1.8 秒 → 马达A 停止1.8
C2马达B 顺时针 功率5 → 等待 1.5 秒 → 马达B 逆时针 功率5 → 等待 0.6 秒 → 停止2.1
C3马达B 抬起 0.5 秒 → 马达A 逆时针 功率6 → 等待 1.8 秒 → 停止2.3
表里的秒数只是起点，不是标准答案。每台车、每块电池都不一样，一定要从同一个起点量出你自己的秒数，写在你自己的路线卡上。改的时候一次只改一个数。
课堂怎么用

一节课只跑一条线

  • 先发空白地图：让学生自己用铅笔画，你在旁边只问一句「开到哪停」
  • 画完对照这三条线：差在哪补哪，不推翻重画
  • 这节课只挑一条跑：按 B → C → A 的顺序，先拿稳分
  • 一段一段验证：同一段连跑 3 次、成 2 次，才画实线、往下接
  • 下课拍照：拍画好的地图 + 程序快照，存档，下次接着跑
打印：按 Ctrl+P 选「A4 横向」，或者直接用 PDF 那份。图上空着的地方，让学生自己补画自己的线。
