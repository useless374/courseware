车辆碰撞检测

车撞墙了，它自己知道吗？
2026-11-13 · 周五 · 55 分钟
今天

本课只做三件事

  • 看见：小车走起来，加速度在屏幕上跳
  • 找线：多大的跳，才算「撞了」
  • 用起来：撞了 → 停车 + 闪灯
复习 · 上节课

三个问题

Q1遥控器按一下，小车收到的其实是什么？
一个数字。遥控器发光，接收头把它翻译成数字。
Q2按了车没动，先查哪两处？
拨码开关是不是「遥控」侧；底座电源有没有开机。
Q3上节课的小车，撞到墙它知道吗？
不知道。它只会「前进」，没有感觉，撞了也继续转电机。
导入

汽车撞了，安全气囊 0.02 秒就弹出来

它怎么知道「这是撞了」，而不是「过了一个坑」？

提示：撞车的一瞬间，车会突然「停住」。停得越猛，变化越大。
靠加速度的突变：传感器每时每刻在量车速的变化，
一瞬间变化太大，就判定为碰撞。
原理

一条线，看出撞没撞

正常行驶加速度在 0 附近小幅波动
起步、停车 ≈ 800
撞墙瞬间加速度突然冲到 1500 左右
一个尖尖的峰

所以要找一条线（阈值）：平时不越过它，撞了才越过。
本课设 1100——比起步停车的 800 高，比撞墙的 1500 低。

单元 1 · 复习

先把遥控三个动作搭好

循环执行：
  如果 红外接收值 = [↑] → 小车前进 速度 200
  如果 红外接收值 = [↓] → 小车后退 速度 200
  如果 红外接收值 = [■] → 小车停止

上节课做过的，快速过一遍；今天它只是「让车动起来」的工具。

单元 2 · 看见

把加速度画成一条线

设置 X = 0
循环执行：
  画点 x = X，y = 映射(加速度X, 从 [-1200, 1200] 到 [0, 64])
  X = X + 0.5
  如果 X > 128 → 屏幕全黑，X = 0
  等待 0.01 秒

横着走的是时间，竖着跳的是加速度——一个「心电图」。

单元 2 · 坑

两个地方最容易画不出来

  • 映射范围写错：必须 -1200 ~ 1200 → 0 ~ 64，数值会跑到屏幕外
  • 忘了清零：X 超过 128 要「屏幕全黑 + X 归 0」，不然线冲出屏幕就不见了

屏幕没有线，先把这两处对一遍，再怀疑传感器。

单元 3 · 找线

把最大的那个数记下来

设置 maxX = 10
循环执行：
  如果 绝对值(加速度X) > maxX → maxX = 绝对值(加速度X)
  屏幕显示 maxX 在第 1 行

先遥控撞墙，看数字冲到多少；再遥控「启动—停止」，看数字到多少。

实测：撞墙 ≈1500，起步/停车 ≈800 → 阈值定 1100。

单元 4 · 反应

超过 1100：停车，闪灯

如果 绝对值(加速度X) > 1100：
  小车停止
  重复 5 次：
    灯 0/1/2 亮红色
    等待 0.5 秒
    全部灯灭
    等待 0.5 秒

这就是「事故报警」：车停住，灯闪，告诉别人我撞了。

关键坑

停车本身，也会被当成「撞了」

  • 急停的一瞬间，加速度也会冲高 → 又触发一次报警
  • 结果：灯停不下来，一直闪

解法：判断到碰撞后，先「等待 0.5 秒」或设一个「已报警」标志，等车停稳再继续检测。

调试

撞了，但没停。先查哪里？

先自己找两分钟。

  • 阈值是不是设太高（屏幕上 maxX 撞墙时是多少？）
  • 比较的是不是「绝对值」——倒车撞墙是负数
  • 判断有没有放进「重复执行」里，只判一次不会生效
  • 碰撞后有没有先等待，被停车尖峰反复触发
  • 车没放平 / 传感器松动，读数一直乱跳
挑战

让它分得清「轻碰」和「撞墙」

  • 调阈值：手轻碰一下就停，还是只有撞墙才停？
  • 加个「警报声」：撞了蜂鸣器也响
  • 加分项：撞完 3 秒后自动恢复遥控，能继续开

只给已经稳定跑通的同学，不额外加时。

收尾

三个问题

Q1小车靠什么知道「自己撞了」？
加速度突然变得很大，超过我们设的阈值。
Q2阈值为什么不能设成 800？
起步和停车就有 800，会误报；要设在 800 和 1500 之间。
Q3为什么撞完要先等一会儿再检测？
急停本身也会产生尖峰，不等就会被自己的停车再次触发。
把手机横过来看，更清楚
