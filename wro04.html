复习 · 上节课

三个问题

Q1珍宝进馆以后，为什么必须先回车停靠圈？
只有安全区和停靠圈里能碰车；在外面碰一次扣 1 分，也没法摆正。
Q2同样是 1 秒，倒车和前进走得一样远吗？
速度差不多，但车尾看不清，对位更难，所以必须单独量。
Q32 分钟的比赛，为什么我们只用 90 秒？
留 30 秒缓冲：摆位、扶正、意外，都需要时间。
段2

为什么回程最容易翻车

  • 珍宝刚放下，车还在博物馆门口
  • 要倒着开回角落的安全区
  • 车尾没有参照物，方向容易歪
  • 停不进安全区 → 后面段3 全卡住

回程是整套路线的「换手点」，它不稳，后面全白搭。

段2 · 做法

倒着开回去

段2（字母 C）： 后退 速度 50 等 N 秒 停止 车尾进安全区停住 → 用手扶正

做完这步：车能在安全区里停住，手够得着

N 是量出来的，不是猜出来的。下面一页讲怎么量。

段2 · 标定

倒车距离怎么量

  • 跑 1 秒，用尺子量车尾退了几厘米
  • 连跑 3 次取平均，写进路线图
  • 换电池、换地面 → 重新量一次
  • 宁可多退 2 厘米，别少退

多退没惩罚；少退进不了安全区，下一段就出不来。

段3

换个角落，再推一件

  • 车在安全区里时，用手搬到另一个角落（规则允许）
  • 从新角落出发，推这个角的珍宝
  • 动作和段1 一样，路线是镜像的
  • 时间不能照抄：两段距离不一样

搬车只能在安全区或停靠圈做，半路上绝不能挪。

段3 · 标定

程序不能复制粘贴

段3（字母 D）： 前进 等 M 秒 ← M 重新量 推 等 K 秒 ← K 重新量 后退 等 P 秒 ← 回停靠

做完这步：第二件珍宝也能 3 次成 2 次

镜子路线只是方向反了，距离没变不代表时间能照抄——先量再写。

进阶

一趟带两件，不绕路

  • 去 B 角的路上，把 A 角的珍宝一起推着
  • 从 B 去博物馆，两件一起送进去
  • 速度降到 50–60%，宁可慢
  • 两件容易互相撞偏，先练单件

两件是加分项。今天做不成，就先按单件跑稳。

第 3 步 · 连起来

全程跑一遍

A → B → C → D → G （段4 球门、段5 奖杯 先跳过） 单段都绿了再合并；合起来失败，退回单段查

做完这步：整条路线一次跑完，中间不用碰车

合并后某段掉链子，先查它在单段里还绿不绿，别急着改程序。

第 4 步 · 计时

90 秒怎么卡

  • 两个时间点：出发 / 回到停靠圈
  • 手机秒表，一人专门盯
  • 目标 ≤90 秒，2 分钟里留 30 秒
  • 超时先查慢在哪段，不急着改

时间大多耗在摆位和扶正，不在车跑的那几秒。

第 5 步 · 判定

3 次成 2 次，然后存快照

全程连跑 3 次： □ 第1次 分 / 秒 □ 第2次 分 / 秒 □ 第3次 分 / 秒 2 次成 → 打印程序，标 v2，路线图涂绿

做完这步：手里有一份能稳定跑 80 分的版本

段0–段3、段6 涂绿；段4、段5 继续空着，下节课再填。

卡住了

三个常见故障

  • 回程撞墙 → 后退时间长了 2–3 秒，先减再试
  • 珍宝滑出门口 → 推太快，进馆后多推 2 厘米
  • 第二件总偏 → 照抄了段1 的时间，重新量

同一段两次失败原因一样 → 改程序；每次都不一样 → 查摆位和电池。
